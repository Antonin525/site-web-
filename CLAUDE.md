# Consignes du dépôt

## Nouveaux sites

Pour **chaque nouveau site** demandé, utiliser le skill `premium-3d-glass`
(`.claude/skills/premium-3d-glass/SKILL.md`) : suivre ses étapes (interview, forme,
contenu, build, vérification, livraison).

Chaque site vit dans son propre dossier à la racine du dépôt (ex. `bella-italia/`).
Dans cet environnement cloud, construire le site dans ce dépôt plutôt que dans
`~/Desktop`, puis commit et push.
